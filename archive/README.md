# Retired experiments

The previous AI chat, routing, news, supply tracking and forecasting experiments
are kept here for reference. None are imported by the local application. Their
original optional dependencies and configuration are no longer installed or
supported by the active app. Git history retains the previous dashboard.

The running application is `fuel_dashboard.py`, `local_data.py`, `fuel_engine.py`,
`forecasting.py`, `data_store.py`, `config.py` and `static/`.
